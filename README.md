# ChatRelay — web viewer

**Live:** https://abh1shxkk.github.io/claude-sync-web/

Static build of the read-only web version of [ChatRelay](https://github.com/Abh1shxkk/claude-sync-releases) (formerly Claude Sync). It opens the AI coding chat history (Claude Code and Codex) that the desktop app pushes to **your own private GitHub repo**, after you sign in with GitHub or enter a token. The token stays in your browser, and the page only talks to `api.github.com`. Nothing from your history is stored here.

If you use a token, make it a fine-grained token limited to that one repo with **Contents: Read-only**.
