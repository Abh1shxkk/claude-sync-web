# Claude Sync — web viewer

Static build of the read-only web version of [Claude Sync](https://github.com/Abh1shxkk). It opens the Claude Code history that the desktop app pushes to **your own private GitHub repo**, using a token you enter in the page. The token stays in your browser, and the page only talks to `api.github.com`. Nothing from your history is stored here.

Use a fine-grained token limited to that one repo with **Contents: Read-only**.
